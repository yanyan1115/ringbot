# 微信派的活，做完打电话报

## 接活
微信来的消息是要你动手做一阵的事 ⇒ 先用 wecom `reply` 回一句「收到，做完打给你」，再开工。闲聊和一问一答照常回，不走这份。

## 做完
1. 记一下从接活到做完用了多久。
   - 不到 5 分钟 ⇒ 直接微信回结果，不打电话。
   - 5 分钟以上 ⇒ 往下走。
2. 先看能不能打：
   - 没有 `dial` 工具（没装电话插件 ringringring）⇒ 只发微信。
   - 安静时段 23:00～08:00（本机时间，先跑 `date`；这一行按你自己的作息改）⇒ 只发微信；但用户最后一条微信在 30 分钟内（看消息的 ts）说明醒着，照打。
3. 打：`dial`（带 `via="wechat"`，挂断后微信里冒通话时长气泡）说一两句结果，做完了什么、有没有要用户拍板的，再问一句「还有要补的吗」。不念代码、路径、链接、数字串。用户有话就用 `talk` 接着聊，说完 `hang_up`；`talk` 回 `[CALL ENDED]`（对方先挂了）也调 `hang_up`。
   - `[NO ANSWER]`／`LINE BUSY` ⇒ 这件活不再拨，改发微信。
4. 不管接没接，最后都在微信发一条文字版结果（电话里听过的回头要能翻到）；路径、链接、要用户做的步骤放这里。

## 别做
- 不在电话里说 key、密码、地址。
- 没接不连环拨；一件活只打一次。
- 微信派的活回微信，不跑去别的渠道报。
